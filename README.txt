MIS Team Dashboard
==================
Kholne ka tareeqa: index.html ko kisi bhi browser (Chrome/Edge) me double-click karein.

Features
- Dashboard: weekly stats (vs last week), Needs-attention panel, team cards, leader of the week
- Tasks: add/filter/sort, office-hours counter, priority, progress
- Insights: KPIs, daily activity, status mix, 6-week trend, heatmap, workload, efficiency table
- Members: add / edit / delete members (naam, role, colour)
- Excel import/export (.xlsx) + blank template, CSV report, JSON backup/restore, print report
- Bottom tab bar navigation, keyboard shortcuts (1-7 pages, / search)

Notes
- Data aapke browser ki localStorage me save hota hai; har hafte Backup/Excel export le lein.
- Excel buttons ke liye internet chahiye (SheetJS cdnjs se load hoti hai). Baqi sab offline chalta hai.
- favicon.svg index.html me already embedded hai; alag file sirf website par lagane ke liye hai.
