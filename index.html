Data & sync

Where your data lives and how it is protected

☁ Live sync to GitHub every change is saved into one JSON file in your repository

↗ Open data file🕘 Change history

The file holds a ready-to-read report (summary, module report, member report, task register) plus the full data for restore. Each save is a GitHub commit, so Change history shows who changed what and when.

💾 Auto-save to a file no token, no login — saves into one file on this computer after every change

Choose the file once (for example mis-data.json inside your MISphere repository folder). After that it is rewritten a moment after every change. To put it on GitHub, commit and push that folder (GitHub Desktop → Commit → Push), then open the file on GitHub to read it. Works in Chrome and Edge. After you reopen the page the browser asks you to allow access once (button “Save now”).

🧰 Settings backup move your configuration to another device or keep a copy

Only configuration (targets, scoring, modules, preferences) is included — never tasks, notes or tokens.
